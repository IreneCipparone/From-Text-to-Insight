# From Text to Insight

## Data Analytics and Linguistic Interpretation of *Stranger Things 5* YouTube Comments

> An end-to-end Natural Language Processing and Data Analytics project combining Transformer-based sentiment analysis, supervised machine learning, unsupervised clustering, and linguistic interpretation.

---

## Project Overview

This project explores how Data Analytics and Natural Language Processing can be used to analyse audience reactions to the official Italian trailer of *Stranger Things 5*.

The analysis is based on a corpus of **866 Italian-language YouTube comments** published under the trailer on the Netflix Italia channel.

The project follows an end-to-end Data Analytics pipeline that transforms unstructured social media text into interpretable insights through:

* linguistic preprocessing;
* exploratory data analysis;
* Transformer-based sentiment analysis;
* supervised machine learning;
* unsupervised clustering;
* data visualisation;
* qualitative linguistic interpretation.

The central objective is not simply to build the most accurate sentiment classifier possible. Instead, the project investigates the relationship between **computational predictions and linguistic interpretation**, with particular attention to the limitations that emerge when machine learning models analyse short, contextualised and emotionally complex social media texts.

---

# Research Question

The project investigates the following question:

> **How can Data Analytics and Natural Language Processing be combined to analyse audience reactions to a highly anticipated media event, and which linguistic phenomena influence the performance and interpretation of automatic text classification models?**

The analysis addresses this question from three complementary perspectives:

1. **Sentiment Analysis**
   What emotional polarity is automatically assigned to audience comments?

2. **Supervised Machine Learning**
   To what extent can a traditional machine learning model based on explicit lexical features reproduce the sentiment labels generated by a Transformer model?

3. **Unsupervised Machine Learning**
   Are there recurring lexical and thematic patterns within the corpus that can be identified without predefined labels?

A final qualitative analysis investigates the linguistic phenomena that may explain model errors and unexpected classifications.

---

The dataset was built specifically for this project using publicly available comments published under the official Italian trailer of *Stranger Things 5* on YouTube.

After data cleaning and duplicate removal, the final dataset consisted of:

The dataset contains the comment text and available metadata collected during the extraction process, including:

The raw and processed datasets are kept separate in order to preserve the distinction between the original collected data and the data used for analysis.

# 1. Data Collection

The corpus was collected from YouTube comments associated with the official Italian trailer of *Stranger Things 5*.

The data collection process was designed to create an original corpus rather than relying on a pre-existing benchmark dataset.

The resulting dataset provides an example of naturally occurring digital language characterised by:

* informal writing;
* emotional expressions;
* references to fictional characters and events;
* shared cultural knowledge;
* expectations about the narrative;
* nostalgia;
* irony and implicit meaning.

---

# 2. Data Cleaning and Linguistic Preprocessing

Social media texts require preprocessing before they can be used in statistical and machine learning models.

The preprocessing pipeline includes:

* duplicate removal;
* removal of empty or non-informative comments;
* lowercasing;
* URL removal;
* removal of user mentions;
* removal of non-relevant special characters;
* punctuation cleaning;
* stopword removal;
* tokenisation;
* lemmatisation.

The resulting processed text is stored in the `clean_text` field.

Additional descriptive variables are calculated to support exploratory analysis, including:

* number of words;
* number of characters;
* lexical frequencies.

The project uses **spaCy** and the Italian language model `it_core_news_lg` for linguistic preprocessing.

---

# 3. Exploratory Data Analysis

Before applying machine learning models, the corpus is explored to understand its general characteristics.

The exploratory analysis includes:

* comment length distribution;
* descriptive statistics;
* identification of outliers;
* lexical frequency analysis;
* identification of the most frequent words.

The corpus is characterised by predominantly short comments.

The median comment length is **5 words**, while the mean is approximately **7.6 words**. The difference between these values reflects a positively skewed distribution influenced by a small number of substantially longer comments.

Among the most frequent lexical items are terms related to:

* the series;
* the final season;
* the trailer;
* characters such as Will, Steve and Vecna;
* the narrative conclusion.

This suggests that the discussion is strongly centred around audience expectations, narrative developments and emotional engagement with the series.

---

# 4. Sentiment Analysis

The sentiment analysis stage uses a pretrained Transformer model for Italian.

The model assigns each comment:

* a sentiment label;
* a confidence score.

The three sentiment categories are:

* **Positive**
* **Negative**
* **Neutral**

The project uses the **Feel-IT** model through the Hugging Face `transformers` library.

## Sentiment Distribution

The analysis produced the following distribution:

| Sentiment | Percentage |
| --------- | ---------: |
| Negative  |      46.1% |
| Positive  |      33.6% |
| Neutral   |      20.3% |

At first glance, the prevalence of negative sentiment may appear surprising for a highly anticipated entertainment product.

However, qualitative inspection reveals an important interpretative issue.

Many comments classified as negative contain expressions related to:

* nostalgia;
* fear of the series ending;
* emotional attachment to characters;
* anxiety about the narrative conclusion;
* sadness associated with the end of a long-term cultural experience.

These examples demonstrate that **negative emotional language does not necessarily correspond to a negative evaluation of the object being discussed**.

This distinction becomes one of the central linguistic insights of the project.

---

# 5. Supervised Machine Learning: Logistic Regression

The sentiment labels generated by the Transformer model are subsequently used as the target variable for a supervised machine learning experiment.

The objective of this stage is not to create a second independent sentiment annotation.

Instead, the experiment investigates:

> **To what extent can a traditional machine learning model based on explicit lexical features reproduce the behaviour of a contextual Transformer model?**

## Text Representation

Comments are transformed into numerical vectors using **TF-IDF**.

The supervised classification configuration uses:

* unigrams and bigrams;
* maximum vocabulary size of 3000 features.

```python
ngram_range = (1, 2)
max_features = 3000
```

The resulting feature matrix contains:

* **866 observations**
* **3000 lexical features**

---

## Train-Test Split

The dataset is divided into:

* **80% training data**
* **20% test data**

A stratified sampling strategy is used to preserve the original distribution of sentiment classes.

---

## Model

The classifier is implemented using:

```text
Logistic Regression
```

The model is evaluated using:

* Accuracy;
* Precision;
* Recall;
* F1-score;
* Confusion Matrix.

---

## Results

The Logistic Regression classifier achieved an accuracy of:

### **59.2%**

The class-level results highlight substantial differences between sentiment categories.

| Sentiment | Precision | Recall | F1-score |
| --------- | --------: | -----: | -------: |
| Negative  |      0.59 |   0.95 |     0.73 |
| Neutral   |      0.00 |   0.00 |     0.00 |
| Positive  |      0.64 |   0.47 |     0.54 |

The results show that:

* the **Negative** class is recognised with high recall;
* the **Positive** class achieves intermediate performance;
* the **Neutral** class is particularly difficult to identify.

The experiment demonstrates that a linear model based primarily on lexical features can reproduce only part of the behaviour of a contextual Transformer model.

---

# 6. Feature Interpretation

One advantage of Logistic Regression is the interpretability of its coefficients.

The analysis of the most influential features reveals different lexical patterns associated with each predicted sentiment category.

Examples include:

| Sentiment | Representative Features                              |
| --------- | ---------------------------------------------------- |
| Negative  | `muore`, `paura`, `spoiler`, `male`, `no`            |
| Neutral   | `ok`, `anni`, `esatto`, `sottosopra`                 |
| Positive  | `finalmente`, `spettacolo`, `queen`, `hype`, `bello` |

The analysis highlights an important limitation of purely lexical classification.

Words associated with death, fear or spoilers may trigger a negative classification even when the user is expressing:

* excitement;
* emotional involvement;
* anticipation;
* concern for fictional characters.

The model can therefore associate the **semantic content of an event** with the **speaker's evaluation of that event**, even when the two dimensions should be interpreted separately.

---

# 7. Unsupervised Machine Learning: K-Means Clustering

The second machine learning experiment applies **K-Means Clustering** to the corpus.

Unlike supervised classification, clustering does not use predefined sentiment labels.

The objective is to investigate whether comments naturally form groups based on lexical similarity.

The analysis includes:

* TF-IDF vectorisation;
* comparison between unigram and unigram + bigram representations;
* Elbow Method;
* Silhouette Score;
* K-Means clustering;
* PCA dimensionality reduction;
* two-dimensional cluster visualisation.

---

## Choosing the Number of Clusters

Both the Elbow Method and the Silhouette Score were used to evaluate different values of `k`.

The corpus did not show a strongly defined natural segmentation.

Nevertheless, the analysis selected:

### **k = 6**

as an operational compromise between cluster quality and interpretability.

The resulting clusters were highly unbalanced:

| Cluster | Number of Comments | Percentage |
| ------- | -----------------: | ---------: |
| 0       |                 53 |       6.1% |
| 1       |                 38 |       4.4% |
| 2       |                 20 |       2.3% |
| 3       |                 12 |       1.4% |
| 4       |                 53 |       6.1% |
| 5       |                690 |      79.4% |

The largest cluster contains the majority of the corpus.

Rather than representing a failure of the clustering algorithm, this result provides information about the structure of the data.

Since all comments refer to the same media event, they share:

* characters;
* narrative references;
* recurring vocabulary;
* emotional themes;
* shared cultural knowledge.

The corpus therefore presents a relatively homogeneous semantic space.

---

# 8. Cluster Interpretation

The analysis of lexical patterns within the clusters reveals several recurring thematic nuclei.

Examples include references to:

* **Will and Vecna**;
* the **Queen soundtrack**;
* emotional reactions such as **chills and excitement**;
* **nostalgia and memories**;
* the long history of the series.

The clusters are not sharply separated, but they reveal recurring thematic tendencies within a corpus characterised by strong lexical overlap.

---

# 9. Linguistic Interpretation of Model Limitations

A central contribution of this project is the integration of quantitative results with linguistic interpretation.

The analysis shows that classification errors cannot always be understood simply as computational failures.

Many difficult cases involve linguistic phenomena such as:

* irony;
* implicit meaning;
* metaphor;
* hyperbole;
* polysemy;
* cultural references;
* shared encyclopaedic knowledge;
* pragmatic context;
* indirect evaluation.

For example, a comment containing words associated with fear or death may receive a negative sentiment label while actually expressing strong emotional engagement and enthusiasm for the series.

This suggests that:

> **Sentiment polarity and evaluation of the discourse object are not always equivalent.**

The project therefore argues that the interpretation of NLP and machine learning outputs benefits from the integration of linguistic perspectives, particularly:

* semantics;
* pragmatics;
* sociolinguistics.

---

# Key Findings

## 1. Sentiment classification requires contextual interpretation

A negative lexical or emotional signal does not necessarily correspond to a negative evaluation of a product or cultural object.

---

## 2. Transformer and traditional machine learning models capture different information

The Logistic Regression experiment achieved an accuracy of **59.2%** when attempting to reproduce Transformer-generated sentiment labels.

This suggests that contextual information captured by the Transformer cannot be fully represented through explicit TF-IDF lexical features.

---

## 3. Neutrality is particularly difficult to model

The supervised classifier failed to reliably identify the Neutral class.

This reflects the difficulty of defining neutrality in natural language, where apparently descriptive statements may contain implicit evaluations.

---

## 4. The corpus is thematically homogeneous

K-Means clustering did not reveal sharply separated groups.

The strong concentration of comments around a single media event results in extensive lexical and semantic overlap.

---

## 5. Quantitative results require qualitative interpretation

Model evaluation metrics provide important information, but they are not sufficient to explain why a prediction was produced.

Linguistic analysis helps identify the pragmatic and contextual phenomena that remain difficult to formalise computationally.

# Limitations

The project has several limitations:

* relatively limited corpus size;
* sentiment labels generated automatically rather than manually annotated;
* difficulty of modelling irony and implicit meaning;
* strong dependence on shared narrative and cultural context;
* thematic homogeneity of the corpus;
* difficulty in identifying the Neutral class;
* clustering performed on a specialised corpus referring to a single media event.

These limitations are not only methodological constraints but also contribute to the central research question regarding the relationship between computational models and linguistic interpretation.
